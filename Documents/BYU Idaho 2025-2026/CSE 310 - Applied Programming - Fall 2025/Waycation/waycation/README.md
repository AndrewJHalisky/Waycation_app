# Overview

As a software engineer, I am trying to challenge myself to utilize the language I am learning to build practical applications.

My app which is called WAYcation allows the user to create their own itinerary by adding events to a calendar, view upcoming events they can attend, and search for prices on hotels, restaurants, and attractions.

My purpose of creating this app was learn more about using TypeScript and how it is used to build mobile apps. I also wanted to learn how to write many different functions that I previously never wrote or used before.

[Software Demo Video](https://youtu.be/pDXePYwjnxs)

# Development Environment

I used React Native. I developed the app using Visual Studio code, and I tested my project using Android Studio.

The programming language that was used to develop this app was TypeScript.
